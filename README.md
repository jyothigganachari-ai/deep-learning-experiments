# 🧠 Deep Learning Experiments

> Neural network architectures, computer vision models, and NLP pipelines — hands-on deep learning.

## 🎯 Objective

Build practical deep learning models from fundamentals (perceptrons) to advanced architectures (transformers), with clear code and visualizations.
